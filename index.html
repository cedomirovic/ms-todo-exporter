Podešavanje (jednom)

Kako da dobiješ client ID (2 minuta)
  1. Otvori Azure Portal → App registrations i klikni New registration.
  2. Naziv, npr. To Do Export. Za Supported account types izaberi Accounts in any organizational directory and personal Microsoft accounts.
  3. Pod Redirect URI izaberi platformu Single-page application (SPA) i upiši tačno ovu adresu: —
  4. Klikni Register i kopiraj Application (client) ID ovde gore.
  5. U API permissions dodaj Microsoft Graph → Delegated → Tasks.Read i User.Read.

Client ID nije tajna — normalno je da stoji u config.js i da ga vidi svako. Tajna je samo ono što korisnik odobri svojim loginom.

Prvo unesi client ID da bi prijava radila. Demo radi odmah.

Kako radi

  • Prijava ide direktno na Microsoft (login.microsoftonline.com) preko OAuth 2.0 + PKCE. Lozinka nikad ne prolazi kroz ovu aplikaciju.
  • Podaci se čitaju Microsoft Graph API-jem i obrađuju lokalno u browseru. Nema backend-a ni baze.
  • Access token se čuva u sessionStorage i nestaje kada zatvoriš tab.
  • Svi datumi se normalizuju prema UTC-u i vracaju u tvojoj vremenskoj zoni.
  • Microsoft je oficialno objavio da se Microsoft To Do gasi — aplikacije će stati 30. juna 2027. Sledeći korak: preuzmi svoje zadatke prema nekom formatu. Službena objava
